# App icon

`AppIcon.png` is the source artwork for Kickoff's macOS app icon. The build generates all standard 16–1024 pixel icon representations and packages them as `AppIcon.icns`; generated icon files stay in the ignored build directory.

The artwork was generated with the built-in image-generation tool. The source preserves the generated alpha transparency. The menu-bar item continues to use the `american.football` SF Symbol for legibility at menu-bar size.

## Generation prompt

Use case: stylized-concept. Asset type: final macOS app icon for Kickoff, a football viewing utility. Create one beautiful, premium, production-ready square app icon, 1024 by 1024. A single unmistakable American football is the hero, sculptural rich warm brown pebbled leather, elegant cream-white laces across the front, two clean white end stripes, an elongated pointed oval silhouette angled upward from lower left to upper right. Bold shape readable at tiny Dock/Finder sizes, tactile dimensional craftsmanship, restrained studio highlights and soft contact shadow. The football fills most of a dark midnight-green rounded-square macOS icon tile, with a subtle luminous field-green atmosphere behind it. Centered balanced composition, crisp contours and refined lighting, feels like a polished native Mac app. The rounded-square tile should occupy about 88 percent of the canvas with genuinely transparent outer corners and margins. Exactly one icon viewed straight on, no device/mockup or surrounding scene. No text, no letters, no numbers, no logos, no watermark, no stadium detail, no soccer ball, no rugby ball. Actual alpha transparency outside the rounded tile, not a drawn checkerboard.
